# Owner playbooks

Use playbooks when you want a business workflow, not a single analysis.

## 1. Pre-scale audit pack

Use before increasing ad spend or launching a campaign.

Run in order:

1. Product Page Conversion Review
2. Checkout Friction Finder
3. Product Feed QA
4. Inventory Risk Brief
5. Paid Traffic Waste Triage

Final output:

- safe to scale
- fix before scaling
- do not promote yet
- needs data
- approval-needed decisions

## 2. Paid traffic loss diagnosis

Use when paid performance gets worse and the cause is unclear.

Run in order:

1. Paid Traffic Waste Triage
2. Product Page Conversion Review for weak landing pages
3. Product Feed QA for catalog-driven campaigns
4. Review and Objection Miner for messaging gaps
5. Inventory Risk Brief for stock or margin constraints

Final output:

- likely leak layer
- evidence by layer
- immediate actions
- tests
- monitoring plan

## 3. Retention deep dive

Use when first purchases happen but repeat purchase is weak.

Run in order:

1. Repeat Purchase Flow Review
2. Review and Objection Miner
3. Support Ticket Theme Miner
4. Weekly E-commerce Growth Readout

Final output:

- missing lifecycle flows
- second-purchase hypotheses
- education gaps
- post-purchase support gaps
- next 3 retention tests

## 4. Inventory and operations review

Use when growth is constrained by stock, returns, or support load.

Run in order:

1. Inventory Risk Brief
2. Returns Reason Miner
3. Support Ticket Theme Miner
4. Weekly E-commerce Growth Readout

Final output:

- stockout risks
- overstock risks
- preventable return themes
- support themes that indicate page/policy/product gaps
- products to promote, hold, or investigate

## 5. Weekly owner operating loop

Use every week.

Run:

1. Weekly E-commerce Growth Readout
2. One specialist skill based on the biggest issue from the readout

Weekly rhythm:

| Cadence | Skill focus |
|---|---|
| Daily optional | Support Ticket Theme Miner for recurring support spikes |
| Weekly | Weekly E-commerce Growth Readout + one specialist skill |
| Monthly | Returns Reason Miner, Repeat Purchase Flow Review, Product Feed QA |
| Before campaign | Product Page Conversion Review, Checkout Friction Finder, Inventory Risk Brief |

Final output:

- what changed
- what matters
- what to do next
- what not to touch yet
